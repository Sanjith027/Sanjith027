### 🚀 About Me

I'm a **Unity XR Developer** with **3.8 years of experience** building VR, AR and MR applications in **Unity and C#** for **Meta Quest, PCVR and mobile**. I've shipped **5+ VR games running in arcades across 10+ malls in India**, working on gameplay programming, VR interaction systems, enemy AI, Photon multiplayer and performance optimization.

Alongside XR, I build **cloud and DevOps projects** on my own time: CI/CD pipelines, containerized deployments on Kubernetes, infrastructure as code on AWS, and monitoring with Prometheus and Grafana. It helps me understand how software is built, shipped and kept running end to end.
